# Linvell Resource Example

Load this directory with **Plugins → Load Development Plugin…** in a source build containing P3. No executable or compiler is needed.

The plugin menu offers Plugin Forest, file icons for Swift/text files and the Greeting Function snippet for Swift documents. Theme/icon activation is explicit and session-only; stopping restores the built-in resources.

See the [bilingual resource guide](https://linvell.fuluwa.top/plugins.html#resources) for the schema and supported snippet syntax.
