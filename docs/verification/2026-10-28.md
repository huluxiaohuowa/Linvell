# Development verification — 2026-10-28

This is evidence for a development preview, not complete-editor acceptance.

## Automated

- 17 focused XCTest cases passed: UTF-8 BOM/CRLF and UTF-16 round trips; external modifications/deletion; save-copy behavior; mixed line-ending protection; symlink and permission preservation; invalid UTF-16 range rejection; binary rejection; failed writes; recovery snapshot persistence; initial Vim counts, cancellation, yank/put, Unicode deletion, insertion entry, delete/undo/redo and word deletion.
- Native debug build passed locally with Xcode 27.1 / Swift 6.4.
- Initial local Universal build produced both `arm64` and `x86_64`; Mach-O build commands reported minimum macOS 15.6 for both. Intel runtime acceptance is not established.
- Final pinned SwiftTerm v1.10.1 resolved, compiled, and passed the same 17 core tests. Its native-terminal runtime recheck is pending after a workstation lock interrupted UI testing.

## Native UI observed

- Native activity rail, explorer, tabs, source editor and categorized settings were opened and inspected.
- A real drag changed the sidebar splitter from 867 pt to 288 pt. Its position restored at 288 pt on restart.
- Expanded `Sources → Linvell` and inspected nested file indentation and disclosure controls; duplicate outline columns were removed.
- Appearance settings displayed the four distinct theme previews. Switching to a light theme was interrupted by workstation lock; the final light-theme UI still needs rechecking.
- iCloud Sync checkbox changed from on to off and immediately displayed “Sync is off. Preferences stay on this Mac.” It was then turned back on. The preference JSON was checked for the expected schema and allowlist only.
- A real terminal started the configured fish shell. After explicitly switching to `/bin/zsh -f`, `test -t 0` printed `LINVELL_PTY_OK`, and `stty size` returned a real terminal size. Ctrl+C returned control from a running command. A native drag changed terminal pane position from 430 pt to 370 pt.
- These terminal observations preceded the final pure-Swift dependency pin; they do not establish full TUI/shell/lifecycle coverage.

## Remaining acceptance

- Workstation unlock is needed to finish final-dependency runtime and light/dark native UI verification.
- Two-Mac iCloud delivery/concurrency, clean-machine download/Gatekeeper first launch, Intel runtime, input methods, large-file performance, full Vim and complete IDE behavior remain unaccepted.
- Signing/notarization and website deployment evidence must be taken from the actual release manifest and live website, not inferred from these source/build checks.
