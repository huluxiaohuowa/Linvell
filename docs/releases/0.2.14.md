# Linvell 0.2.14

- Search the complete history reachable from local repository refs, including branches, tags and fetched remote-tracking refs. Match commit hashes, authors, email addresses, full messages and ref names. Search runs in the background, replaces stale results, and loads matching pages on demand. Press Command-F in Source Control to start searching.
- Choose a local target branch when finishing a worktree. Resolve conflicts by comparing both versions, keeping either side or editing in Linvell. Continue or abort the merge from the conflict sheet. To reopen the sheet after editing, finish the same source worktree into the same branch again.
- Choose whether to remove the clean source directory after the merge. Cleanup preserves the source branch and retains directories containing ignored files or new changes.
- Unstage all files without changing their working copies.

## 中文

- 搜索本地仓库引用可达的完整历史，包括分支、标签和已获取的远程跟踪分支。可匹配提交哈希、作者、邮箱、完整提交信息和引用名，支持后台搜索、取消过期查询和结果分页。源代码管理界面按 Command-F 可聚焦搜索框。
- 完成工作树时可选本地目标分支。遇到冲突可比较双方版本、保留一侧或用 Linvell 手工编辑，再继续或中止合并。手工编辑后，可再次对同一源工作树和目标分支执行完成操作，重新打开冲突面板。
- 合并后可选是否移除干净的源目录。清理保留源分支，并跳过含忽略文件或新改动的目录。
- 支持全部取消暂存，保留工作区文件内容。
