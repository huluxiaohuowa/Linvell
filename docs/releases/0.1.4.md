# Linvell 0.1.4

- 修复“项目工具”异步加载卡片时触发 Auto Layout 异常并闪退的问题；覆盖概览与系统资源页。
- 重做源代码管理的三栏布局：分支导航、改动／提交图谱、差异详情。Git Commit Graph 在视图菜单和命令面板中可直接打开；文件状态使用可读标签，长路径单行截断。增加按变更块暂存／取消暂存。
- SSH 工作区支持选择远程文件夹，并以可展开的多级目录树浏览。展开子目录不会更改项目根目录；取消新连接的文件夹选择会保留当前工作区。
- Markdown 源码与预览双向同步垂直滚动；关闭、重开预览时保存文档滚动位置。
- 活动栏选中项增加亮暗主题下的底色和侧边指示条。设置 → 外观 → 启动，可选择空白欢迎窗口或恢复上次的本地项目／SSH 远程文件夹；Finder 指定打开的目标优先。
- 回滚版本最多保留一个压缩包；自动迁移旧更新器遗留的隐藏 `.app` 副本，避免它们继续出现在 Finder“打开方式”中。
- Swift Vim 引擎增加次数与操作符组合、修改命令、单词／括号／引号文本对象、字符查找与重复、命名及系统剪贴板寄存器、标记、单字符替换、合并行、大小写切换、`.` 重复及插入会话撤销。
- 增加普通／插入模式的宏录制和回放、`R` 替换模式及退格恢复、正反向／整词查找、带行范围的 Ex 替换与删除／复制。尚未支持的正则语法和替换参数会提示错误，不会静默按其他规则执行。
- 可视选择支持文本对象、次数和字符查找；多光标支持文本对象修改与带次数删除。新增 VS Code 常用行快捷键：移动／复制、删除、注释、缩进和上下插入新行。

应用与新增编辑引擎均为 Swift 原生实现，不嵌入 Vim、Neovim、Chromium 或 VS Code 扩展宿主。系统 Vim 仅用于开发测试中的隔离样例对照。

**兼容范围仍在扩展：** 当前尚非完整 Vim 或完整 VS Code 编辑兼容。完整 Vim 正则、映射、完整 Ex、可视／替换宏、完整块寄存器及部分复合命令仍需继续开发；Vimscript／Vim9、VSIX 扩展宿主不包含在此版本中。Git 面板不等同于 Sublime Merge 的全部功能。Intel 真机验收尚未完成。
