# Linvell 0.1.1

- 修复 Finder 打开文件时，启动阶段额外创建默认欢迎窗口的问题；文件直接打开，文件夹作为项目打开。
- 添加 Finder“服务 → 用 Linvell 打开”入口，可接收选中的文件和文件夹。
- 新欢迎页、葫芦标志和独立设计的字标；改善设置按钮的对比度。
- 支持中文／英文界面即时切换，并声明 macOS 应用语言支持。
- 字体菜单自动列出本机已安装的等宽字体，增加原生“所有字体…”面板。
- 图片预览，以及 Markdown／HTML 右侧实时预览；HTML 支持同目录样式与脚本。
- 修复关闭双栏后剩余编辑器未扩展到全宽的问题；修复语言刷新后图标按钮出现文字的问题。
- 添加初步的项目工具页：运行时版本、包清单、Git 活动和系统指标。包管理写操作、数据库和任务链仍在开发。

版本改为正常语义版本，后续默认递增 patch；版本脚本可显式传入 minor 或 major。

本地 Universal 构建，要求 macOS 15.6 及以上。完整 Vim、完整 IDE、Intel 真机验收、跨 Mac iCloud 到达及高刷帧率验收仍未完成。大文件性能尚未与 Sublime 做同条件对比。

官网：https://linvell.fuluwa.top/
