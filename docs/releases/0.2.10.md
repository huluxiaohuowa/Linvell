# Linvell 0.2.10

- Show every newly opened Agent session in the left sidebar immediately, before the first message. Update its title during conversations and reuse its running terminal when selected.
- Refresh saved sessions automatically and merge records using the owning process's session identity. Use a private Codex server when supported to avoid ambiguous shared-daemon ownership.
- Replace the embedded DSH website with the native interactive terminal. DSH requires a separately installed compatible TUI; an existing DSH account login remains owned by DSH/TUI.
- Display installation guidance when the selected Agent has no usable CLI, including the separate DSH TUI requirement. Prevent repeated DSH startup clicks, report startup failures, and fix the terminal viewport height and resumed-session readiness handling.
- Disable iCloud synchronization for development-script launches so test app copies do not request iCloud access.

Local real-account acceptance covered Codex and DSH. DSH `0.2.1-rc.5` was tested with separately installed dsh-TUI source commit `83fcf892d49c4f4e5b05fab2936fac2241bad579`; TUI is not bundled. Other providers have fixture coverage; remote real-account TUI acceptance was not run.

Signed, notarized Universal macOS app for Apple Silicon and Intel. Requires macOS 15.6 or later.
