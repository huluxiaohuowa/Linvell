# Linvell 0.2.25

- Project Search groups matches by file, can match case, searches unsaved edits and selects the exact match. In Git projects it skips ignored files unless they are open with edits.
- Quick Open puts recent files first and supports `file:line` and `:line`. Use Control-Tab and Control-Shift-Tab to switch tabs.
- The local and SSH file trees support duplicate, project file and folder creation, path copying, keyboard navigation and pinned parent folders. The local tree also offers Show in Finder.
- Recent Projects can remove individual entries or clear the list. Files opened through Finder or the Open dialog use the containing project. Settings can restore project tabs independently of startup behavior and follow macOS light or dark appearance.
- Existing files keep their indentation style. Toggle Comment uses the language’s delimiters, including block comments in HTML, CSS and Markdown.
