# Linvell 0.1.0 — Development Preview 1

首个开发预览版：原生 Swift/AppKit 工作区、葫芦标识、可调整侧栏与分屏、四套浅深色主题、分类设置和可选 iCloud Drive 偏好同步。

包括文件树、标签、基础代码高亮、查找替换、文件与命令快速搜索、项目文本搜索、只读 Git 状态、真实 PTY 终端，以及 Swift 实现的初步 Vim 命令集。文件读写保留编码和换行格式，并检查磁盘外部变更；本地恢复快照不会上传到云端。

## 下载

- macOS 15.6 或更新版本。
- Universal：Apple Silicon / Intel 双架构二进制；本机 Apple Silicon 验证，Intel 真实运行尚未验证。
- 提供 DMG、ZIP、`SHA256SUMS.txt` 与 `release-manifest.json`。
- 本地构建，Developer ID 签名、Hardened Runtime、Apple 公证与应用内附加票据；通过 GitHub Releases 分发，不走 Mac App Store。

## 已知限制

这是早期开发预览，**不具备完整 Vim 或完整 IDE 功能**。Visual/Replace、宏、完整寄存器、Vimscript/Vim9、LSP、调试、任务、远程文件和完整 Git 写操作等仍在开发。项目搜索和高亮有明确大小上限；iCloud 跨 Mac 到达仍需多设备验证。请参阅仓库的 `docs/STATUS.md`。

---

A native Swift/AppKit foundation with a gourd-inspired identity, resizable workspace, four light/dark themes, categorized settings and optional iCloud Drive preference sync. Built locally and distributed only through GitHub Releases.

This is an early development preview. Full Vim and the complete IDE workflow remain in progress. Apple Silicon runtime has local validation; Intel runtime and cross-Mac iCloud delivery are not yet accepted. See the source repository's development status for detailed limits.
