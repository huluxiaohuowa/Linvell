# Linvell 0.2.7

- Switch the displayed terminal together with the selected agent provider and local/SSH execution location. Restore the last selected session for that combination; show an explicit empty state when none exists, while other sessions keep running.
- Keep provider/location controls synchronized when selecting an open session. Include the execution host in session menu labels.
- Keep New Session available for setup guidance: explain missing CLI selection or DSH task input, and connect the remote project mount before starting a local agent.
- Add SSHFS/macFUSE installation guidance for local agents accessing SSH projects: installation detection, a copyable Homebrew command, official instructions, recheck and connect actions. Installation detection is separate from live mount validation.
- Show mount controls outside collapsed advanced settings. Separate history-discovery messages from runtime and launch status, so background refresh cannot hide a missing prerequisite or replace the selected runtime's status.

Signed, notarized Universal macOS app for Apple Silicon and Intel. Requires macOS 15.6 or later.
