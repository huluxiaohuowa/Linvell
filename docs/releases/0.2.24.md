# Linvell 0.2.24

- Integrated Silica’s syntax highlighting rules for 25 languages in the editor, Markdown code fences and Git review. Colors follow the active theme.
- Search project text over SSH from the Search sidebar or ⇧⌘F. Select a match to open the file at its matching line.
- Rename SSH files and folders from the file tree. Open tabs follow the renamed paths. Move items to the SSH host’s Trash without permanently deleting them.
- Dim files and folders ignored by Git in the SSH file tree. Tracked files remain undimmed.

## 中文

- 集成 Silica 的 25 种语言高亮规则，覆盖编辑器、Markdown 围栏代码块和 Git 审查，配色跟随当前主题。
- 在 SSH 工作区通过搜索侧栏或 ⇧⌘F 搜索项目全文，选择结果可跳到对应行。
- 在 SSH 文件树里重命名文件和文件夹，已打开的标签会跟随新路径。移到废纸篓会保留文件在 SSH 主机上。
- SSH 文件树会淡化 Git 忽略项，已跟踪的文件仍正常显示。
