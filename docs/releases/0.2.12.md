# Linvell 0.2.12

- Open Source Control on working changes. Separate working and staged files with counts, and retain the selected file or commit on refresh when it is still visible.
- Stage all working changes with one action. Keep partially staged files in both lists and show the diff for the selected side. Clear the commit message after a successful commit.
- Highlight the checked-out branch and diff additions and deletions. Put file and review actions next to the diff and show a clear empty state when there are no changes to review.

## 中文

- 源代码管理默认显示工作区改动。工作区和已暂存列表分别显示文件数，刷新后优先保留仍可见的文件或提交。
- 支持一键全部暂存。部分暂存的文件在两个列表中分别显示对应的 diff。提交成功后清空提交说明。
- 突出当前分支和 diff 增删，将文件与审查操作放在 diff 上方，并为无改动的列表显示明确提示。
