# Linvell 0.2.11

- Add named task workspaces: create an isolated `codex/…` branch and Git worktree from HEAD, open it in a separate native window, and scope its agents to the task directory. Reopen tasks or existing worktrees from the Project menu and toolbar. Task names persist; removal refuses dirty/locked worktrees and preserves branches.
- Add review comments on selected editor lines and working-tree, staged or untracked diff lines. Save workspace-scoped source snapshots with paths, old/new line references and feedback; preview or remove saved comments.
- Collect review comments into a draft and paste them into a selected live agent in the exact workspace and host. Bracketed paste prevents automatic submission, terminal controls are stripped, and Copy Draft remains available.
- Add English and Simplified Chinese menus, task prompts and review controls. Task creation currently requires a local Git repository with a commit; commit-history diff review is not included.

## 中文

- 新增命名任务工作区：从 HEAD 创建独立 `codex/…` 分支与 Git worktree，在独立原生窗口中运行，Agent 会话限定于任务目录。支持重新打开任务／已有 worktree；名称跨重启保存，移除时拒绝脏／锁定的 worktree，并保留分支。
- 新增代码选区及未暂存、已暂存、未跟踪文件 diff 的审查批注，保存路径、旧／新行号、代码快照和意见，可预览并逐条移除。
- 汇总批注为草稿，粘贴到准确工作区、主机中的指定运行中 Agent。使用 bracketed paste，不自动提交，过滤终端控制字符；也可复制草稿。
- 提供中英文菜单与操作提示。任务创建目前要求本地 Git 仓库至少有一次提交；不包含提交历史 diff 的批注。
