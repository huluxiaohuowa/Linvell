# Linvell 0.2.16

- Review working files, file history and commit patches in one panel. Expand multiple patches together or individually, independently of folder folding.
- Preview and select worktrees for cleanup, including branches integrated through squash or rebase when Git can verify equivalent content. Review ignored files before removal and optionally delete local branches that Git confirms are merged.
- Refresh visible worktree status automatically, with staged, unstaged, untracked, conflict and ahead/behind counts.
- Search command logs, filter failures and jump from operation errors to the matching records. Set Auto Fetch intervals and view the most recent successful Fetch.
- Configure graph visibility, relative commit times, default patch expansion and external applications in Git settings. Use the Git menu for review, diagnostics and Fetch shortcuts.

## 中文

- 在同一个审查面板查看工作区文件、文件历史和提交差异。支持同时展开多个差异，也可逐份展开，目录折叠独立控制。
- 逐项预览并选择要清理的工作树。Git 能验证内容等价时，也可识别 squash 或 rebase 合入。移除前可预览忽略文件，并选择删除 Git 确认可安全删除的本地分支。
- 自动刷新可见的工作树状态，显示暂存、未暂存、未跟踪、冲突和领先、落后的数量。
- 搜索命令日志、筛选失败项，并从操作错误跳到对应记录。可设置自动 Fetch 间隔并查看上次成功时间。
- 在 Git 设置中控制提交图、相对提交时间、差异默认展开和外部应用。Git 菜单新增审查、日志和 Fetch 快捷操作。
