# Linvell 0.1.6

包含 0.1.5 的远程子目录选择修复、远程 Git 工作面板和全应用自适应显示调度。

- 发布构建迁移到标准 GitHub-hosted macOS runner，由 CI 完成 Universal 应用、DMG／ZIP、Developer ID 签名、Apple 公证和 GitHub Release 发布。
- 手动触发默认递增 patch，可显式选择 minor／major；稳定版本 tag 也可触发对应版本构建。
- 签名与公证凭据保存在仓库 Actions Secret，只包含本应用发布所需的共用字段；临时配置与钥匙串在任务结束后清理。
- 增加真实 SSH Git 端到端回归，验证历史、独立变更块暂存／取消暂存、分支和提交；支持符号链接目录的真实路径解析。
