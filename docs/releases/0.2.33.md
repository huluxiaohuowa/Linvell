# Linvell 0.2.33

- The Explorer shows hidden files and folders by default in local and SSH workspaces, including nested items. To hide them from the tree and its file filter, turn off **Show hidden files and folders** under **Settings → Appearance**.

## 中文

- 本地和 SSH 工作区的资源管理器默认显示隐藏文件和文件夹，包括子目录里的隐藏项。可在「设置 → 外观」关闭「显示隐藏文件和文件夹」，目录树和「筛选文件」会一起隐藏这些项目。
