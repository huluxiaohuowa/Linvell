# Linvell 0.1.2

## SSH 远程开发

默认读取 `~/.ssh/config` 的主机别名及 Include 配置，沿用系统 SSH 的密钥、代理和跳板设置。支持远程目录浏览、新建文件、打开／编辑／保存、文件名快速搜索和 SSH 终端。保存前校验远端内容，检测到外部修改时阻止覆盖。远程文件协议需要 POSIX Shell 和 Python 3，单文件上限 16 MiB。

## 运行与网页预览

新增“运行与预览”面板：选择任务或输入命令、实时交互日志、运行与停止。本地命令在本机项目目录执行，SSH 命令在远程主机执行。远程 Web 服务可通过仅绑定本机回环地址的 SSH 端口转发，在右侧隔离的网页预览中打开。

## Git 与 Git Graph

本地仓库新增改动列表、工作区／暂存区差异、暂存与取消暂存、提交、分支切换／创建、获取、仅快进拉取和推送。历史根据实际父提交关系绘制分叉和合并连线，显示分支／标签及最多 150 条提交，并可查看提交补丁。

## 多选与 Vim

保留 VS Code 风格快捷键及 Sublime 式同词多选。新增矩形列选（⇧⌥拖动，或 ⇧⌥⌘方向键）、按行分配粘贴，以及 Vim 的 v／V／⌃V 可视、行、块选择；支持选区删除、修改、替换、复制、块首／尾插入和多位置操作。单次列选最多 10,000 行。

开发构建使用独立身份，不再与安装版争抢 Finder 文件关联。

完整中英文说明：https://linvell.fuluwa.top/guide.html

## 支持范围

当前没有 VS Code 扩展宿主、Dev Containers、完整 LSP／DAP、完整 Vim 或 Sublime Merge 的全部历史改写及三方冲突编辑功能。Git 面板管理本地工作副本。高级 VS Code 任务依赖与变量展开未导入，可直接输入展开后的运行命令。Intel 已 Universal 编译，尚未进行 Intel 真机验收。

所有应用构建、签名及 Apple 公证均在本地进行，仅通过 GitHub Releases 分发。
