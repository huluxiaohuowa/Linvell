# Linvell 0.2.21

- Preview PDF files inside editor tabs with macOS PDFKit, including continuous scrolling and automatic page fitting.
- Embed macOS Quick Look for Office documents, iWork files, audio, video and other recognized document formats. Available previews depend on the system and installed preview providers; no document-rendering engine is bundled.
- Show an inline message for unsupported binary files instead of the unsupported-text alert. Local and SSH files share the same read-only preview behavior, protecting previewed files from text saves, autosave and language/plugin editing.

## 中文

- 在编辑器标签页内使用 macOS PDFKit 预览 PDF，支持连续滚动与自动适配页面。
- 使用系统 Quick Look 预览 Office、iWork、音视频及其他可识别文档。实际支持范围取决于系统和已安装的预览提供程序，无需捆绑文档渲染引擎。
- 不支持的二进制文件改为在右侧显示文字提示，不再弹出“不支持文本”的错误窗口。本地和 SSH 文件均采用只读预览，避免文本保存、自动保存以及语言服务或插件修改预览文件。
