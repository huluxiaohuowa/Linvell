# Linvell 0.2.23

- Click anywhere on a tab to select it, or drag it within the tab strip to reorder it. The strip scrolls when you drag near either end.
- Local and SSH workspaces remember their own tab order and active file across restarts and when reopened from Recent Projects.
- Added Atom One, GitHub, Xcode and Gruvbox in light and dark, plus Solarized Dark.

## 中文

- 单击标签即可切换文件，拖拽标签即可排序。拖到标签栏两端时可滚动到其他标签。
- 本地和 SSH 工作区分别保存标签顺序和活动文件，重启或从最近项目重新打开时可恢复。
- 新增 Atom One、GitHub、Xcode 和 Gruvbox 的深浅主题，以及 Solarized Dark。
