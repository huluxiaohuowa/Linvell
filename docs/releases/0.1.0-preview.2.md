# Linvell 0.1.0-preview.2

本次开发预览补齐常用语言文件图标、VS Code 风格快捷键，以及多选同词、跳过当前匹配、选中全部匹配、追加光标和按行拆分选区。多光标支持连续输入、替换、删除与撤销/重做。

- 修复 Vim Normal 块光标在改变选区后残留于旧位置的问题，鼠标定位不再依赖 Escape 重绘。
- 改善行距、行号栏、长行换行、主题终端配色和视图裁剪。
- 添加 Finder 文件 URL 拖入处理；物理跨应用拖放仍需继续验证。
- 后台加载文件，维护增量行索引，避免每次移动光标扫描全部前文；简化大文件的换行检测。
- 更新设置支持自动检查、自动下载和退出时安装的独立开关。自动下载、安装默认关闭。安装会等待保存确认和正常退出，并保留旧应用以供恢复。

本地 Universal 构建，Developer ID 签名与 Apple 公证，通过 GitHub Releases 提供 DMG、ZIP 和 SHA-256 校验文件。要求 macOS 15.6 或更新版本；Intel 真机运行尚未验收。

这是早期开发预览。完整 Vim、IME/多光标组合输入、LSP、调试、任务、远程文件与 Git 写操作仍在开发，iCloud 跨 Mac 到达仍需验证。大文件速度尚未与 Sublime 做同条件对比。
