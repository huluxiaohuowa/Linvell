# Linvell 0.2.13

- Browse recent and pinned repositories, group them by name, and import Git repositories directly inside a local folder. Search the list and sort by recency or name.
- Browse linked worktrees by branch and open them in separate workspaces. Add, move, lock, unlock, remove clean worktrees, or prune stale entries. Finish a clean, unlocked worktree by fast-forwarding the current branch and removing its directory while keeping its branch.
- Browse local branches, remote branches, and tags. Compare two references, track a remote branch, or start branch, tag, merge, stash, and conflict actions with the selected values filled in.
- Switch between current-branch and all-reference history. Filter loaded commits by author, email, subject, hash, or reference, load older commits, and jump to HEAD from the Git menu.
- Filter changed files and optionally fold them by folder. Choose unified, side-by-side, or width-based diff presentation. Both diff presentations support line review comments.
- Insert the configured commit template, amend the previous commit, and opt in to automatic fetch while a repository is visible. Auto Fetch runs fetch only.

## 中文

- 浏览最近打开和固定的仓库，设置自定义分组，也可批量导入本地文件夹直属的 Git 仓库。支持搜索以及按最近打开或名称排序。
- 按分支查看关联工作树，在独立工作区打开，支持新建、移动、锁定、解锁、移除干净的工作树和清理失效记录。完成工作树时可快进当前分支，移除干净且未锁定的源目录，并保留源分支。
- 浏览本地分支、远程分支和标签，比较任意两个引用，跟踪远程分支，并从所选条目带入分支、标签、合并、贮藏和冲突处理操作。
- 支持当前分支与全部引用历史，按作者、邮箱、说明、哈希或引用筛选已加载提交，可继续加载更早的记录，并从 Git 菜单跳转到 HEAD。
- 支持筛选改动文件与按目录折叠，提供统一、并排和按宽度自动切换的 diff 视图。统一与并排视图均可做行批注。
- 支持插入仓库配置的提交模板、修订上一次提交，以及按仓库启用自动 Fetch。自动 Fetch 只获取远程更新。
