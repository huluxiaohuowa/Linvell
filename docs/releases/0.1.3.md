# Linvell 0.1.3

包含 [0.1.2](https://github.com/huluxiaohuowa/Linvell/releases/tag/v0.1.2) 的 SSH 远程开发、运行／停止／网页预览、Git 管理与 Git Graph、VS Code 风格快捷键及普通／Vim 多选和块选择。

- 修复远程登录 Shell 为 fish 时，终端启动命令的语法兼容问题。远程命令通过明确的 POSIX 启动层进入主机配置的登录 Shell，运行环境继续沿用该主机的 Shell 配置。
- 增加 POSIX／fish 启动与路径含空格、引号时的测试；重新验证真实 SSH 运行、转发、网页预览和远程服务停止。
- 发版脚本默认读取已提交的应用版本，不需要重复输入版本号。`python3 script/update_version.py` 默认只增加 patch；可显式传入 minor／major。

中英文使用指南及支持边界：https://linvell.fuluwa.top/guide.html

本地 Universal 构建，Developer ID 签名及 Apple 公证；仅通过 GitHub Releases 分发，要求 macOS 15.6 及以上。Intel 真机验收仍未完成。
