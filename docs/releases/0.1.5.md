# Linvell 0.1.5

- 修复远程文件夹选择：单击选中的子目录就是打开目标；进入子目录后直接打开也得到同一路径。按钮显示具体目标目录名，加载期间不能打开旧目录。
- 修复远程项目点击 Git 时误弹文件夹选择器。远程仓库复用同一套三栏 Git 工作面板，支持状态、提交图谱、差异、分支、暂存／取消暂存、变更块、提交和网络操作；文件打开仍走对应 SSH 主机。
- 为整个应用的原生滚动区域统一启用图层支持和响应式滚动，包括远程选择器、文件树、编辑器、Git、设置、项目工具与图片预览。窗口交互使用所在屏幕的显示同步回调，不固定锁定 60 Hz，并在交互结束后停止额外调度。
- 终端及运行日志的解析、光标和显示更新接入窗口共用的显示调度，替代终端依赖中的固定 16.67 ms 合并延迟；SwiftTerm 库源码与最小补丁、来源和 MIT 许可一并保存在仓库中。
- 远程目录行视图和文件夹图标复用，减少滚动期间反复创建控件与约束。

当前 120 Hz 屏幕的显示回调实测中位间隔约 8.33 ms；20,000 项目录样例的可见行布局 P95 小于 1 ms。这些分别是回调和 CPU 布局指标，不能等同于所有内容每一帧都稳定呈现 120 FPS。实际刷新节奏仍由屏幕能力及系统功耗策略决定。

远程 Git 使用系统 SSH 配置、Git 及现有认证；写操作需要点击对应按钮。远程文件浏览仍需要 Python 3。完整 Vim／VS Code 编辑兼容的已有支持边界保持在使用指南中。
