# Linvell 0.2.18

- Add repository sorting by recent file changes and date added, ascending/descending order, and group membership editing.
- Add direct file, hunk and selected-line index actions in single and multiple reviews, including partial new-file staging. Show source line numbers in unified and split patches.
- Add hybrid commit dates, full commit messages, merged-commit browsing, selected-commit comparison, comparison swapping, and incoming/outgoing badges and counts.
- Add image zoom, actual-pixel display, transparency backgrounds and renamed-image comparisons. Review stashes, including untracked files and images, in the shared review panel. Support BOM-encoded UTF-16 source previews and in-file search.
- Add multiline commit snippets with favorites, application choices, command-log copy/clear/read filters, and creation and push of individual tags.
- Schedule Auto Fetch for saved repositories independently of the visible Git view, with defaults and repository overrides.
- Hold prepared Git HEAD/reference locks through worktree cleanup. Include detached worktrees, keep recent or unstarted worktrees unchecked, and allow safe source-branch deletion after merging.
- Verify native Git workflows over OpenSSH from macOS to an isolated Linux ARM64 fixture, including index operations and conflict/cleanup workflows.
- Fix native review sizing and preserve review-comment behavior. Keep FoldGit's MIT copyright and license in the shipped notices.

## 中文

- 补齐按文件最近修改、添加时间排序和升降序，以及分组成员管理。
- 单文件与多文件审查支持直接按文件、修改块、所选行暂存和取消暂存，包括新文件的部分暂存；统一与并排差异显示源文件行号。
- 新增混合提交时间、完整提交说明、合入提交浏览、所选提交比较、交换比较方向，以及待拉取／待推送标记和数量。
- 图片支持缩放、实际像素、透明棋盘背景和重命名前后比较；stash 的未跟踪文件与图片接入统一审查面板；源文件预览支持带 BOM 的 UTF-16 和文件内查找。
- 补齐多行提交片段与收藏、应用选择、命令日志复制／清空／只读过滤，以及创建并推送单个标签。
- 已保存仓库的自动获取更新不再依赖当前是否显示 Git 视图，支持默认设置和仓库覆盖。
- 工作树清理全程持有 Git HEAD／引用锁，支持 detached 工作树，近期活跃或未开展工作的条目默认不选；合并后可安全删除源分支。
- 使用 macOS 到独立 Linux ARM64 主机的真实 OpenSSH 连接验证暂存、冲突、工作树清理和原生审查流程，所有测试均在隔离目录中运行。
