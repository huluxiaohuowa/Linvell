# Linvell 0.2.8

- Replace SSHFS/macFUSE requirements with optional, user-installed Mutagen for local agents editing SSH projects.
- Show `brew install mutagen-io/mutagen/mutagen` when missing, and a green capability indicator when installed. Actual synchronization status is displayed separately.
- Synchronize a private per-host/project replica in two-way-safe mode before launching a local agent; preserve conflicts and pending edits. Remote shell commands still require SSH.
- Start an isolated synchronization process only for an explicit connection check or a local agent session on an SSH project. Stop it when the last dependent session ends or the workspace closes; register no login item and bundle no Mutagen runtime.
- Preserve the left session sidebar and independent concurrent local/SSH provider sessions.
- Refresh clean remote editor buffers after synchronized agent changes. Preserve dirty buffers, suspend automatic saves on external conflicts, and reject stale remote saves. Surface Mutagen conflict paths without forcing an overwrite.
