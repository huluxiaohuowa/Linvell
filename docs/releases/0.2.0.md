# Linvell 0.2.0

Linvell 原生插件接口首次随正式版本提供，覆盖 P1–P5。

- 本地开发包、独立进程宿主、Swift SDK、命令、文档事件、可撤销范围编辑、菜单、快捷键、配置和持久状态。
- 声明式原生树／列表、状态栏、设置表单和工具窗口；主题、图标、代码片段及纯资源插件。
- LSP 语言服务声明接入补全、诊断、跳转、重命名和格式化；插件任务使用原生终端；新增 DAP 调试与有界内存日志。
- SSH 工作区插件宿主、按平台选择程序、SHA-256 校验传输、进程停止及显式重连。独立 Swift SDK 可在 Linux 构建插件；编辑器仍为 macOS 应用。

插件只在显式加载后执行。代码插件以用户权限运行，不是安全沙箱；不兼容 VSIX／Nova／Vim 插件，也不包含插件商店或自动安装。DAP 首版支持 launch／内部控制台，完整边界见接入指南。

Requires macOS 15.6+. Universal Apple Silicon / Intel application, signed with Developer ID and notarized by Apple.

开发者指南：https://linvell.fuluwa.top/plugins.html
