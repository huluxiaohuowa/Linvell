# Linvell 0.2.15

- Clone a repository and open it in Source Control. Rename repository display labels, archive inactive repositories, and drag repository rows to set their order.
- Highlight changes within lines using FoldGit’s MIT-licensed algorithm. Wrap long diff lines, stage or unstage a directory, and resize the two visible change lists.
- Reuse repository history search batches across queries. Browse the files in a commit, or open a file’s commit history and inspect a file-only patch.
- Show linked worktree status, preview and remove multiple worktrees whose commits are reachable from a selected branch, and check for conflict markers before staging a manually resolved file. Cleanup keeps locked, dirty, open and ignored-file worktrees.
- Manage reusable commit snippets, view and export a repository’s session command log, and inspect fetch errors. The log records command names, duration and outcomes without arguments or output.

## 中文

- 克隆仓库后直接进入源代码管理。支持仓库显示别名、归档和拖拽排序。
- 使用 FoldGit 的 MIT 授权算法突出行内差异。支持长行换行、按目录暂存或取消暂存，以及同时查看并拖动调整两份改动列表。
- 多次历史搜索复用已读取的索引批次。可按文件查看某次提交，或从文件历史查看单文件差异。
- 显示关联工作树状态，预览并批量移除提交已进入所选分支的工作树。清理保留已锁定、打开、有改动或有忽略文件的工作树。手工标记冲突已解决前检查残留标记。
- 支持维护和插入提交短语、按仓库查看与导出本次会话的 Git 命令日志，以及查看 Fetch 失败详情。日志记录命令名、耗时和结果，省略参数和输出。
