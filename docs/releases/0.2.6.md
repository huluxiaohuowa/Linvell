# Linvell 0.2.6

- Bind the Agent workbench to the current project directory and SSH host. Opening an SSH project no longer reuses a running local project's session list or launch configuration.
- Show the local/SSH execution selector for remote projects, defaulting new remote workbenches to SSH. Local-agent access to remote files continues to require a validated live SSHFS mount.
- Keep each project's existing sessions and PTYs running when switching projects. Returning to the original project restores its workbench and process; window/application shutdown covers sessions retained in other projects too.
- Refresh the binding when connecting to SSH, choosing a different remote folder, resolving the remote root, or returning to a local folder. Keep the left Session list, search and resume interface.

Signed, notarized Universal macOS app for Apple Silicon and Intel. Requires macOS 15.6 or later.
