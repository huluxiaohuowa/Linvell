# Linvell 0.2.19

- Add repository multiselection for creating groups, moving repositories between groups and archiving. Preserve relative ordering when dragging multiple repositories. Allow Finder imports and repository filtering inside the group editor.
- Add repository/worktree path copying, including multiselection, following FoldGit 0.4.1.
- Keep worktree cleanup in a native review/results panel with Refresh, Select All/Deselect All, grouped ignored-file counts, per-item outcomes and copyable recovery commands. A branch-deletion failure is reported separately from successful worktree removal; no force deletion is used.
- Show staged file, insertion, deletion and binary-file counts. Add the commit-area visibility preference and direct favorite-snippet buttons while preserving the entered message.
- Retain FoldGit's MIT notices and validate the Git workflows locally and through real OpenSSH to an isolated Linux ARM64 fixture, including mixed cleanup outcomes.

- 仓库支持多选新建分组、批量移动分组和归档；多选拖动保留相对顺序；在分组编辑器中直接从 Finder 导入并筛选仓库。
- 补齐 FoldGit 0.4.1 的仓库／工作树路径复制，并支持批量复制所选仓库路径。
- 工作树清理使用原生预览／结果面板，支持刷新、全选／取消全选、忽略文件分组数量、逐项结果和复制恢复命令。分别报告工作树移除与分支删除结果，继续禁止强制删除。
