# Linvell 0.2.9

- Open DeepSeek Harness in its installed official Web UI, embedded in the Agent workspace. No additional TUI installation is required.
- Create a blank DSH conversation without entering a task. Double-click a saved conversation to restore its exact session ID and history, including after its process has stopped.
- Reuse DSH's existing account login and official default-model initialization instead of launching a headless task against an unconfigured API-key route. Linvell does not read or copy account credentials.
- Keep independent DSH conversations alongside other Agent sessions. SSH DSH connections use loopback port forwarding and the remote installation's credentials.

Local acceptance used an installed DSH with an existing login: blank creation, a real model response, running-session activation and stopped-session restoration passed. Live remote DSH account acceptance was not run.

Signed, notarized Universal macOS app for Apple Silicon and Intel. Requires macOS 15.6 or later.
