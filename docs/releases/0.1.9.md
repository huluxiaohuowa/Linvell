# Linvell 0.1.9

## 交互修复 / Interaction fixes

- 悬浮提示改为紧凑、不抢键盘焦点的原生卡片，移除大按钮。离开符号、滚动、输入或切换窗口时关闭，取消旧请求，迟到结果不会重弹。
- 增加 ⌥← / ⌥→ 返回／前进，并保留 VS Code macOS 的 ⌃- / ⌃⇧-。返回会恢复文件与光标位置，迟到的 SSH 文件读取不再抢回焦点。
- 修复 SSH 工作区打开“项目工具”误弹文件夹选择器，工具数据取自目标主机。
- 本地／远程项目设置统一使用窗口顶部项目名称旁的按钮，项目工具页也提供同名入口。
- 欢迎页新增最近项目：显示名称与路径，远程项带“远程 · 主机”前缀，点击在当前窗口重开。按最近打开顺序去重，最多十二项；旧版本的上次工作区记录会迁入，历史不进入 iCloud。

## 原生代码智能 / Native language-client workflow

- 能力协商、UTF-16 增量／完整同步、协议级请求取消与保存选项；修复过期请求占用队列，以及不读取输入的服务阻止进程退出的问题。
- 本地文件系统事件与远程后台元数据监视；远程索引未变化时只返回摘要，不反复传输文件列表。网络失败保留缓存，扫描不进入输入或滚动路径。
- 项目语言服务配置通过 LSP 配置通道生效，支持根目录语言配置和各语言的 `linvell.languageServerSettings`，保留 JSONC 注释与其他设置。路径宏按所属主机展开。
- 相同程序、解释器、参数与配置复用后端，包括混合 JavaScript/TypeScript 项目。最后一个相关文档关闭时释放共享进程和监视器。
- 真实文档／工作区符号，声明、类型定义、实现、参数提示、格式化和问题列表。支持推送与拉取诊断、结果 ID、刷新请求及相关文件；跳转、补全和重命名保留版本校验与原生撤销。
- 状态栏显示连接及服务报告的分析进度；提供“重启语言服务”。“已连接”不代表所有文件已经完成索引。

Compact nonactivating hover cards, working Option-arrow navigation, host-aware Project Tools, consistent Project Settings and recent local/SSH projects. The Swift language client now negotiates synchronization, cancels wire requests, watches workspace changes, shares matching backends and exposes semantic symbols, parameter hints, formatting and diagnostics with native UI.

语义索引由所选语言服务提供；具体操作须由该服务支持，导入别名按语言作用域处理。新文件需保存路径后进行项目分析。语义分析仍限制为单文件 2 MiB，重命名最多 500 文件／32 MiB，远程元数据监视最多 20,000 文件。基础词法编辑不依赖语言服务。本版不引入 Chromium 或 VSIX 扩展宿主。
