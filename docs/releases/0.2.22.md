# Linvell 0.2.22

- The compact workspace puts tabs in the title bar and uses Liquid Glass for the editor and Quick Open on macOS 26 and later. Shared controls, Git, SSH, Agent, plugin windows and dialogs follow the active theme.
- Added ten themes, including Catppuccin, Tokyo Night, Rosé Pine, Dracula/Alucard, Linvell Sea Glass and Linvell Ember. The editor, minimap, Git Diff and fenced Markdown code blocks share syntax colors.
- Added a clickable minimap, indentation guides, Go to Line, wrap and font-reset shortcuts, ranked Quick Open, and nested file filtering. The local file tree dims Git-ignored entries and offers file and folder creation, rename and Move to Trash.
- The last local or SSH workspace can restore file tabs. Tab context menus can reorder tabs and close other tabs. SSH Quick Open ranks by filename and shows relative paths.
