# Linvell 0.2.32

- Added a workspace opacity slider in Appearance. The file explorer, welcome view, and editor update as you drag, and Linvell remembers the setting. The title bar and tab strip stay opaque.
- Reduced drawing during editor scrolling by reusing the minimap and updating syntax colors only as new text enters view.

## 中文

- 「外观」新增工作区不透明度滑杆。资源管理器、欢迎页和编辑区随拖动即时更新，重启后保留设置。标题栏和标签栏保持实色。
- 编辑器滚动时复用小地图，只为新进入可视范围的文字更新语法高亮，减少重复绘制。
