# Linvell 0.2.26

- Increased transparency in the workspace and welcome screen. The editor uses clear Liquid Glass on macOS 26 and later while respecting Reduce Transparency.
- Gave line numbers and folding controls a dedicated gutter. Horizontally scrolling text stays inside the editor viewport.

## 中文

- 提高工作区和欢迎页的玻璃通透度。macOS 26 及更新版本的编辑区采用更通透的 Liquid Glass，并尊重系统的「降低透明度」设置。
- 行号和折叠按钮使用独立栏位。横向滚动时，正文会裁切在编辑区内。
