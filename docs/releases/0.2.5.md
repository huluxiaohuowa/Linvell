# Linvell 0.2.5

- Keep the left Agents sidebar, searchable saved-session list and resume controls. Move optional CLI/home/mount configuration into Agent Settings.
- Run multiple sessions concurrently, including different agent providers. New Session and provider selection remain available while sessions run.
- Switch open sessions in the main workspace without terminating their processes or discarding terminal output, scrollback or images. Resuming a session already running in this instance reattaches its existing terminal.
- Stop only the selected session, even if the user switches sessions before termination finishes. Workspace/application shutdown stops all remaining agent processes after confirmation.
- Open terminal file links and selected file paths in the current Linvell workspace, including relative paths, line locations, images and SSH-owned paths. Support inline terminal images through the existing SwiftTerm graphics protocols.
- Fix macOS inline terminal images rendering blank by drawing into the retained bitmap representation.
- Fix DeepSeek Harness titles by reading concatenated Zstandard frames and later title events; tolerate the unfinished tail of a live log.

Signed, notarized Universal macOS app for Apple Silicon and Intel. Requires macOS 15.6 or later.
