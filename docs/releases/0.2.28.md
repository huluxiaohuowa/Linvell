# Linvell 0.2.28

- Restored translucent material in the editor and welcome area. The title bar and tab strip have a solid background, so windows behind Linvell stay out of the traffic-light and tab areas.
- The workspace uses a solid background when macOS Reduce Transparency is enabled.

## 中文

- 编辑区和欢迎页恢复半透明材质。标题栏和标签栏使用实色背景，后方窗口不会透进红绿灯和标签区域。
- macOS 开启「降低透明度」时，工作区使用实色背景。
