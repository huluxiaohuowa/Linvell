# Linvell 0.1.8

## 项目语言服务 / Project language services

- 新增独立的“项目 → 项目设置”，显示当前文件夹与所属主机；语言工具不再放在应用通用设置中。
- 按需下载 Python（Pyright）、JavaScript/TypeScript 语言服务，无需把它们打进应用安装包。其他语言仍支持已有 SDK 或自定义语言服务器。
- SSH 项目由本机下载并校验目标平台的安装包，再通过 SSH 上传安装，目标主机无需联网下载；成功、失败或取消后清除本机临时中转文件。
- 每种语言独立选择安装到项目 `.linvell/tools`，或代码所在机器用户的 `~/.linvell/language-services`。配置保存在项目根目录 `.linvell/settings.json`，支持混合语言项目并保留 JSONC 注释及其他设置。
- 项目模式提供安装时自动添加 Git 忽略规则的开关，以及一键添加按钮。规则写入项目根目录 `.gitignore`，不重复添加，保留 `settings.json` 的可跟踪性。
- 一键清理 Linvell 管理的服务；其他已登记项目仍在使用的用户目录共享服务会保留，解释器与项目源码不受影响。JavaScript 和 TypeScript 共用一个后端。
- 语言服务按需启动，关闭最后一个已同步文档后退出；基础分词、语法高亮和普通编辑不依赖语言服务。

- Dedicated folder- and host-scoped Project Settings, separate from application preferences.
- On-demand Python and JavaScript/TypeScript services with verified client downloads and SSH upload, without requiring Internet downloads on the remote host.
- Per-language project or host-user storage, idempotent root Git ignore rules, safe shared-service cleanup and automatic service shutdown after the last synchronized document closes.

本次不捆绑语言服务器，不安装 VSIX 或 Chromium。语言服务安装目录、解释器路径不会通过 iCloud 同步到其他机器。自动安装支持 macOS 与 glibc Linux 的 x64/ARM64 目标，SSH 文件通道使用目标主机已有 Python 3。
