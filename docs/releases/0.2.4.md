# Linvell 0.2.4

- Include the existing Agent integration for Codex, OpenCode, Pi, Claude Code and DeepSeek Harness. Select an agent/session in the left Agents sidebar and run it in the main workspace; switching to files preserves the same process and terminal.
- Coalesce repeated Agent-session discovery and retain tab rows during editor refreshes.
- Refresh clean files changed by an agent while protecting unsaved edits and refreshing expanded directories.
- Reuse pending syntax analysis across split panes and repeated requests for the same document revision; newer edits still cancel outdated work.
- Maintain remote directory cache capacity counters under the existing lock, avoiding a full entry-count scan on each cache insertion while preserving aliases, replacement and eviction limits.
- Fix SSH task and terminal startup when the user's login configuration is incompatible with `/bin/sh`; only the selected user shell now reads its login configuration.
- Add Homebrew Cask distribution through `huluxiaohuowa/tap/linvell`. Stable GitHub Releases automatically update the tap after verifying the published archive checksum. Official Homebrew Cask inclusion is separate and remains pending.
- Split long plugin confirmation expressions for compatibility with the CI Swift compiler, preserving their text and behavior.
- Route updates by installation source: manual installations use GitHub Releases; Homebrew installations check their Cask source and show a brew upgrade command instead of replacing the app.
- Include persistent plugin installation and management from the previously committed main branch.

Signed, notarized Universal macOS app for Apple Silicon and Intel. Requires macOS 15.6 or later.
