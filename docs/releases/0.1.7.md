# Linvell 0.1.7

## 编辑体验 / Editing

- Swift 原生词法分析：常用编程语言的基础分词、语法高亮及忽略注释／字符串的括号匹配。本地与 SSH 文件使用同一实现。
- 代码折叠：括号块、Python 缩进块、HTML/XML 标签及常见关键字块；支持函数、类、结构体等结构。点击行号旁箭头或使用 ⌥⌘[ / ⌥⌘]；⌘K ⌘0 全部折叠，⌘K ⌘J 全部展开。折叠不修改源码或未保存状态。
- 按语言和缩进风格自动缩进；设置新增相对行号，当前行显示绝对行号。
- Native Swift lexical highlighting, bracket matching, structural folding, language-aware indentation and optional relative line numbers for local and SSH documents.

## 项目工具 / Project tools

- 可选本地／远程自动保存，未保存圆点和关闭 X 切换，检测外部修改，保留编码与换行。
- 定义／引用跳转、导航历史、悬浮提示、补全和诊断；使用项目所属主机上已安装的语言服务器。
- 每项目、每语言的解释器／编译器配置保存在根目录 `.linvell/settings.json`，支持 JSONC、多个语言和远程主机路径。
- 语义跨文件重命名、修改预览、整体撤销与保存全部。
- 原生 submodule 管理与更多 Git 操作表单，包含分支、合并／变基、stash、标签、远程、reflog 和 worktree；交互命令可使用内置 Git 控制台。
- Optional conflict-safe auto-save, host-aware per-project language tools, semantic navigation/completion/rename, and native Git/submodule management.

## 更新与流畅性 / Updates and responsiveness

- SSH 连接复用、缓存目录浏览及显式刷新；无需从 GitHub 下载常驻 Linvell server。
- GitHub 不可达或响应无效时依次尝试多个加速端点，包含 ghfast；下载仍经过 SHA-256、Apple 签名与版本验证。
- 待安装更新仅保留 ZIP，安装时短暂解压；删除前注销临时应用，回滚只保留一个压缩版本，修复 Finder 重复“打开方式”。
- Reused SSH connections, cached directory lists, multi-endpoint GitHub download fallback and cleanup of temporary application handlers. Signature and checksum requirements remain enforced.

语言服务器需自行安装；词法分析与基础编辑功能不依赖语言服务器。语义分析有文件／重构大小限制，详见使用指南。高级 Git 命令可通过参数表单或交互控制台执行；本版不包含图形三方合并编辑器。刷新率跟随屏幕能力，未承诺所有场景的每一帧均达到屏幕最高刷新率。

See https://linvell.fuluwa.top/guide.html for Chinese and English instructions, supported workflows and limits.
