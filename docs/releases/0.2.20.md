# Linvell 0.2.20

- Compare commits automatically in selection order, compare any revision with the working tree, swap endpoints and retain aggregate statistics. Read complete commit messages, navigate parents and introducing merges, and follow renamed files through their historical paths.
- Review files in a keyboard-navigable directory tree or flat list. Filter and fold continuous full-height diffs; retain syntax highlighting, similarity-aligned split rows, synchronized wrapping, image comparisons, visible Find, and whole-file/line/hunk index actions. Refresh open reviews after working-tree, index and history changes.
- Organize repositories in collapsible groups and inactive sections, interleave groups and repositories by dragging, review validated imports, and clone with progress and cancellation. Discover, pin and revisit installed folder-opening applications.
- Create new-branch, existing-branch and detached worktrees. Review the target branch, destination and commits before finishing; resolve conflicts and continue or abort, then separately review and retry cleanup. Protect active windows, agents, pending operations and changed snapshots, and migrate worktree organization, tasks and review metadata safely.
- Share fetches across windows and scheduled/manual actions, retain background errors and per-repository retry/settings, establish upstream tracking on first push, and share worktree visibility across linked checkouts. Add scoped Git menu commands, a shortcut reference, synchronized diff appearance and reviewed Git-default restoration.
- Correct native sheet sizing, long-path presentation and theme appearance. Retain FoldGit's MIT copyright and full license; validate local workflows, native windows and real OpenSSH end-to-end workflows before publishing.

## 中文

- 按选择顺序自动比较提交，支持任意版本与工作区比较、交换两端和汇总统计。完整显示提交说明，支持父提交与引入合并的导航，并沿重命名前后的路径浏览文件历史。
- 审查窗口支持键盘导航的目录树和列表；筛选、折叠与连续完整高度的差异同步，补齐语法高亮、相似行配对、两栏换行对齐、图片比较、可见内容查找和整文件／行／区块暂存操作。工作区、索引或历史变化后自动刷新。
- 仓库支持可折叠分组、不活跃区域、分组与独立仓库交错拖动排序、校验后预览导入，以及带进度和取消的克隆；外部应用支持系统发现、固定和最近使用。
- 工作树支持新分支、已有分支与分离 HEAD。完成前检查目标分支、目标目录和待合并提交；处理冲突后继续或中止，再单独检查、执行或重试清理。保护打开的窗口、运行中的智能体、未完成的 Git 操作及已变化的快照，并迁移组织、任务和审查记录。
- 多窗口与自动／手动获取共享请求，保留后台错误并支持逐仓库重试与设置；首次推送建立上游关联，关联工作树共享可见性设置。补齐有焦点范围的 Git 菜单、快捷键说明、同步的差异外观设置和经确认的 Git 默认设置恢复。
- 修复原生窗口尺寸、长路径显示及主题外观。保留 FoldGit 的 MIT 版权和完整许可证，发布前完成本地、实际窗口与真实 OpenSSH 端到端验证。
